# Anshel Code Market — Agent instructions

For any UI design, frontend implementation, or redesign in this repository:
1. Read `.agents/skills/frontend-design/SKILL.md` before planning or writing UI code.
2. Establish a distinctive direction specific to a source-code marketplace. Avoid generic AI-generated SaaS hero sections, arbitrary gradients, repeated identical cards, decorative code blocks, and unsupported product claims.
3. After changing UI, read `.agents/skills/web-design-guidelines/SKILL.md`, fetch its current referenced guidelines, and audit the changed files.
4. Fix critical usability, keyboard, mobile, and accessibility issues before deploying.
5. Keep example products clearly labeled as demos; do not claim payments, downloads, or admin features work until implemented and tested.
6. Report what was actually verified and what remains incomplete.

Source skills are stored in `.agents/skills/`. Do not replace these files with summaries.
