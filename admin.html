KONFIGURASI DIPERLUKAN

Database marketplace belum terhubung.

Dashboard sudah disiapkan, tetapi proyek Supabase khusus Anshel Market belum diaktifkan. Ini tidak menggunakan database Anshel Virtual Tech atau proyek lain.

Langkah penyambungan
  1. Buat proyek Supabase terpisah untuk Anshel Code Market.
  2. Jalankan skema supabase/schema.sql pada proyek tersebut.
  3. Buat pengguna admin melalui Supabase Auth dan tambahkan UUID-nya ke tabel market_admins melalui SQL Editor.
  4. Atur SUPABASE_PROJECT_URL dan SUPABASE_PUBLISHABLE_KEY pada konfigurasi Vercel.

Jangan memasukkan service-role key, password database, atau kredensial rekening ke website maupun repositori.
