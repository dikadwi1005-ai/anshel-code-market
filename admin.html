KONFIGURASI DIPERLUKAN

Database marketplace belum terhubung.

Dashboard sudah disiapkan, tetapi proyek Firebase khusus Anshel Market belum dikonfigurasi. Belum ada database marketplace yang terhubung.

Langkah penyambungan
  1. Buat proyek Firebase khusus Anshel Code Market, aktifkan Firestore dan Authentication Email/Password.
  2. Pasang aturan keamanan firebase/firestore.rules di Firestore Rules.
  3. Buat pengguna di Firebase Authentication, kemudian buat dokumen market_admins/{UID} melalui Firebase Console.
  4. Atur FIREBASE_API_KEY, FIREBASE_AUTH_DOMAIN, FIREBASE_PROJECT_ID dan FIREBASE_APP_ID pada Vercel.

Konfigurasi web Firebase adalah publik. Jangan memasukkan private key, service-account JSON, password admin, atau kredensial rekening ke kode publik. ZIP membutuhkan paket Blaze.
